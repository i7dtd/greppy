# greppy

`greppy` — небольшая консольная утилита для поиска строк по регулярному
выражению. По интерфейсу она похожа на `grep` и поддерживает поиск в одном
или нескольких текстовых файлах.

## Возможности

- поиск по POSIX Extended Regular Expressions;
- нечувствительный к регистру поиск;
- инвертированный поиск;
- вывод количества совпавших строк;
- вывод только имён файлов с совпадениями;
- вывод номеров строк;
- объединение нескольких шаблонов через несколько опций `-e`.

## Требования

Для сборки необходимы:

- Unix-подобная операционная система;
- `gcc`;
- `make`;
- стандартная библиотека C с поддержкой `regex`, `getopt` и `getline`.

## Сборка

Клонируйте репозиторий и перейдите в каталог проекта:

```sh
git clone <URL_РЕПОЗИТОРИЯ>
cd greppy
```

Соберите программу:

```sh
make
```

После успешной сборки в корне проекта появится исполняемый файл `greppy`.

Для полной пересборки используйте:

```sh
make rebuild
```

## Установка

По умолчанию программа устанавливается в `/usr/local/bin`:

```sh
sudo make install
```

После установки `greppy` можно запускать из любого каталога:

```sh
greppy 'pattern' file.txt
```

Другой каталог установки можно указать через переменную `PREFIX`:

```sh
make PREFIX="$HOME/.local/bin" install
```

В этом случае каталог будет создан автоматически. Убедитесь, что он добавлен
в переменную окружения `PATH`.

## Удаление

Для удаления установленной программы выполните:

```sh
sudo make uninstall
```

Если использовался собственный `PREFIX`, укажите его снова:

```sh
make PREFIX="$HOME/.local/bin" uninstall
```

## Использование

Общий формат команды:

```text
greppy [-eivcln] pattern file...
```

### Опции

| Опция | Описание |
| --- | --- |
| `-e PATTERN` | Добавить шаблон поиска. Опцию можно указывать несколько раз. |
| `-i` | Игнорировать регистр букв. |
| `-v` | Вывести строки, которые **не** соответствуют шаблону. |
| `-c` | Вывести количество совпавших строк для каждого файла. |
| `-l` | Вывести только имена файлов, в которых найдено совпадение. |
| `-n` | Добавить к каждой найденной строке её номер. |

Шаблон можно передать как первый аргумент после опций или через `-e`.

## Примеры

Найти строки, содержащие слово `main`:

```sh
greppy 'main' greppy.c
```

Найти `error` без учёта регистра и вывести номера строк:

```sh
greppy -in 'error' greppy.c README.md
```

Вывести строки, которые не содержат комментарии:

```sh
greppy -v '^#' greppy.c
```

Посчитать совпадения в нескольких файлах:

```sh
greppy -c 'TODO' greppy.c README.md
```

Вывести только имена файлов с совпадением:

```sh
greppy -l 'typedef' greppy.c README.md
```

Искать по нескольким шаблонам:

```sh
greppy -e 'error' -e 'warning' greppy.c
```

Шаблоны, передаваемые через `-e`, объединяются оператором `|`, поэтому
используйте кавычки, если шаблон содержит специальные символы регулярных
выражений.

## Коды завершения

- `0` — команда выполнена без ошибок;
- `2` — ошибка аргументов, регулярного выражения или чтения файла.

## Команды Makefile

| Команда | Назначение |
| --- | --- |
| `make` | Собрать программу. |
| `make install` | Установить программу в `$(PREFIX)`. |
| `make uninstall` | Удалить установленную программу. |
| `make clean` | Удалить собранный бинарный файл. |
| `make rebuild` | Выполнить очистку и полную сборку заново. |

По умолчанию `PREFIX` имеет значение `/usr/local/bin`.
